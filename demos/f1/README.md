# F1 demo

Beat-synced Max Verstappen 2021 edit built with Framewright, finished in DaVinci Resolve. Five versions, from a
first beat plan (v01) to a 60 fps looping edit with cut-outs and typed titles (v05), then v05 built as an
editable Resolve timeline. See `output/README.md`.

## Inputs (not in git)

| File | What it is |
|---|---|
| `input/footage/f1_footage_1.mp4` | Raw footage A (2:44, 1080p60) |
| `input/footage/f1_footage_2.mp4` | Raw footage B (6:54, 1080p60) |
| `input/reference_edit.mp4` | 14 s reference edit the structure and look were matched to |
| `input/music/f1_audio.m4a` | 14 s song excerpt; `output/shared/f1_audio.wav` is its WAV copy |

The scripts expect these exact file names. Sources and credits: [CREDITS.md](../../CREDITS.md).
